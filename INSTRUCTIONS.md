# Objectif
Store de roms pour batocera, avec un serveur (API, en Rust) et un client (Rust/SDL2).

Les roms sont organiser comme sur batocera, avec les images et le gamelist.xml dans le même répertoire que les plateformes.

Le client doit être pilotable avec une manette de jeux, et permet de télécharger en local directement la rom/iso dans le bon répertoire, avec les images/medias et regénérer le gamelist.xml en fonction, comme si je scrappais.
